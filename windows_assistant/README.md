# Windows Voice Assistant (Python 3.12)

Локальный голосовой ИИ-ассистент для Windows 10/11.

## Возможности
- Слушает микрофон и распознаёт речь на русском.
- Выполняет команды:
  - открыть приложение/сайт;
  - напечатать текст;
  - нажать клавиши;
  - переместить мышь;
  - сделать скриншот;
  - создать `.txt` файл;
  - найти файл;
  - выполнить безопасную системную команду (по whitelist).
- Отвечает на базовые вопросы (дата/время/возможности).
- Перед потенциально опасными командами всегда требует подтверждение голосом.

## Установка
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r windows_assistant/requirements.txt
```

## Vosk модель (офлайн распознавание)
1. Скачайте модель `vosk-model-small-ru-0.22`.
2. Распакуйте в `windows_assistant/models/vosk-model-small-ru-0.22`.

Если модель не установлена, можно временно отключить офлайн режим в `config.py`.

## Запуск
```bash
cd windows_assistant
python main.py
```

## Примеры команд
- `открой сайт ya.ru`
- `запусти notepad.exe`
- `напечатай Привет, мир`
- `нажми ctrl + s`
- `перемести мышь 800 400`
- `сделай скриншот`
- `создай файл заметка: купить молоко`
- `найди файл report`
- `команда whoami`

## Политика безопасности
Команды с шаблонами опасных действий (удаление, терминал, платежи, пароли и т.п.) сначала запрашивают подтверждение фразой `подтверждаю`.
Без подтверждения операция отменяется.

## Важно
- Проект рассчитан на локальное использование.
- Для некоторых действий может потребоваться запуск от имени пользователя с нужными правами.
- `pyautogui` управляет активным окном — перед автопечатью и хоткеями убедитесь, что фокус в нужном приложении.


## Сборка в `.exe` (Windows)

Самый простой путь — через **PyInstaller**.

### Вариант 1: готовый bat-скрипт
В папке проекта есть `build_exe.bat`:
```bat
cd windows_assistant
build_exe.bat
```
После сборки файл будет в:
- `windows_assistant\dist\WindowsVoiceAssistant.exe`

### Вариант 2: вручную
```bat
cd windows_assistant
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install pyinstaller==6.9.0

pyinstaller --noconfirm --clean --name WindowsVoiceAssistant --onefile --console --collect-all vosk --hidden-import pyttsx3.drivers.sapi5 main.py
```

### Что важно для запуска `.exe`
1. Папка с моделью Vosk должна быть рядом с EXE в ожидаемом пути:
   - `models\vosk-model-small-ru-0.22`
2. Если не нужна офлайн-модель, можно отключить `use_vosk_offline` в `config.py`.
3. Для работы микрофона и автодействий (клавиатура/мышь) запускайте от пользователя с нужными правами.
